# OpenRouter

**Setup:**

1. Preset: **OpenRouter**
2. Create a key at **https://openrouter.ai/keys**
3. Paste the key, **Test Connection**, **Apply**
4. Pick a model.

::: tip Free models
The "Free models only" checkbox filters the model list to IDs ending in `:free`.
Very handy for trying the add-in at zero cost.
:::
